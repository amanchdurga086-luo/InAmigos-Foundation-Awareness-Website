# InAmigos Foundation Awareness Website

A complete, modern, responsive NGO awareness landing page for **InAmigos Foundation** built using only **HTML5** and **CSS3**.

The website highlights the NGO's mission, projects, impact, gallery, and volunteer call to action. It is designed to look professional, accessible, beginner-friendly, and ready to run by opening `index.html` in a browser.

## Features

- Sticky responsive navigation bar
- About section with image and key focus areas
- Mission and vision cards
- Six project cards using CSS Grid
- Impact statistics section
- Responsive image gallery with hover zoom
- Why Join Us feature cards
- Full-width call-to-action section
- Footer with quick links, projects, contact details, and social icons
- Smooth scrolling and CSS hover animations
- Semantic HTML structure with accessible image alt text

## Technologies Used

- HTML5
- CSS3
- Google Fonts
- Font Awesome Icons
